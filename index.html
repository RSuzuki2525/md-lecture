MD講義デモ

学部3年 · 分子動力学（MD）入門

MDは、古典力場から粒子の動きを計算し、統計力学で物性に変える方法だと説明できる

入力：古典力場エネルギーの式 → 力が決まる
計算：MD力 → Δt ずつ運動を進める。温度・圧力の条件をそろえる
出力：統計力学粒子の動きの平均 → 構造・相・拡散などの物性
  1. 1
    入力：古典力場

    LJ粒子の箱 — 力はポテンシャルから

    • ε・σ のスライダーで U(r) の形を変える → 粒子のかたまり方が変わる（周期境界と温度だけのシンプル表示）
    • 粒子をクリック → 相手が井戸の底に集まる。矢印＝合力
    • 小分子の力場（ブタン）：結合・角度・二面角を1つずつ変えて MD。ニューマン投影図でトランスとゴーシュの入れかわりを見る。「結合をはじく」で振動、Δt を大きくすると爆発
    • クーロンはスライドで
    8 分
  2. 2
    計算：運動を進める

    ジャンプで学ぶ時間積分 — 積分法と Δt

    • Δt を 0.1 s 以上にして「3つ同時に比較」（← → で3体いっしょに動く）
    • 飛んでいる間に「時間を逆回し」→ 速度ベレ法だけが踏み切った点に戻る。エネルギーのずれもベレ法だけ 0
    • 分子の振動（バネでつながった2原子）：オイラー法は発散、ベレ法はエネルギーが一定で逆回しすると元にもどる
    8 分
  3. 3
    計算：条件をそろえる

    サーモスタットの部屋 — NVE / NVT / NPT

    • NVE でキャラを走らせる → 温まる・冷える → 「温度を保つ仕組みが要る」
    • NVT でサーモスタットを比べる → NPT で温度を上げると部屋がふくらむ。温度・体積・圧力のグラフで見る
    10 分
  4. 4
    出力：統計力学で物性へ

    LJ粒子の箱（もう一度） — 構造・拡散・結晶化

    • 周期境界と「まわりのコピー」→ 少ない粒子で大きな物質をまねる
    • 熱する → 気体。MSD が直線にのびる → 傾き ÷ 4 = 拡散係数 D
    • 急冷 と ゆっくり冷やす を比べる（色＝結晶の向き）→ 多結晶 と 1つの結晶。MSD は横ばい、g(r) にピーク
    • 壁で囲むと g(r) が変わる → 表面の影響
    • 速さの分布：ヒストグラムがマクスウェル分布に重なる。温度で山の位置と幅が変わり、固体でも気体でも温度だけで決まる
    • 高分子の鎖：一端を壁、もう一端をキャラにつないで引っぱる（エントロピー弾性・力–のび曲線）。溶媒を変えて Rg を比べる（コイル ↔ グロビュール）
    • メルトで「やや硬い」鎖を急冷 と ゆっくり冷やす → ガラス と 結晶（U/N と S を比べる）
    10 分
