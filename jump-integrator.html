方法エネルギーのずれ ΔE/E₀逆回しの戻り誤差

点線＝理論の最高点。軌跡の点1つ＝1ステップ。Δt を 0.1 s 以上にすると差がはっきり見える。
逆回し＝速度を反対向きにする。正しく戻れば、踏み切った点にぴったり着地する（戻り誤差 0）。逆回し中はキーを押さない。

ジャンプ中のエネルギー（踏み切りからの時間）：ΔE/E₀ = (½v² + g·h − ½v₀²) / ½v₀²
分子の振動で比べる：バネでつながった2原子（周期 1 s）。Δt は上のスライダーと共通
方法エネルギー E/E₀逆回しの戻り誤差

オイラー法は振動がどんどん大きくなる（エネルギーが増える）。速度ベレ法はエネルギーがほぼ一定で、逆回しすると元の位置にもどる。

1ステップの更新式（a = 加速度）

オイラー法

x ← x + v·Δt
v ← v + a·Δt

古い速度で位置を進める。ジャンプが高すぎる。

半陰的オイラー法

v ← v + a·Δt
x ← x + v·Δt

順番を入れ替えただけ。ジャンプが低すぎる。多くのゲームはこれ。

速度ベレ法

x ← x + v·Δt + ½a·Δt²
v ← v + ½(a + a_new)·Δt

重力一定ならステップ上の位置は厳密。MDの標準。
